② 哪些东西变了 参数 什么时候变 训练与使用

刚才反复提到“内部数字”，我们把它讲实一点。前面模型把输入信息变来变去、把不同信息组合起来，这些计算需要大量可以调整的数字。它们共同影响模型怎样处理输入、怎样产生后续结果。这些在训练中被调整、训练后需要保存的内部数字，叫作“参数”。

可以把参数暂时想成一张很大的内部设置表。但它不是“一格负责毕业论文日期，另一格负责学姐语气”的知识清单。很多数字共同参与计算，一个数字也可能影响许多不同问题。做题时使用它们，训练时改变它们，练完要保存改变。

所以，模型输出的概率与模型参数不是同一样东西。参数是本轮计算所用的内部数字；概率是带着这些数字、处理当前输入后算出的结果。我们刚才看到“打”的概率，是一次预测的结果。训练要调整的是背后参与计算的参数，不能把训练理解成给每个答案手工填写一个概率。

② 哪些东西变了 参数 什么时候变 训练与使用

现在对比两个动作。第一个动作：我们给模型一道题，它算出答案，我们把答案读完。这叫使用模型。在通常的使用过程中，参数保持不变。第二个动作：我们准备练习目标，让程序计算偏差、调整参数，并保存调整结果。这才是在训练模型。

因此，在聊天框里纠正它“你刚才说错了”，它在接下来的对话中可能会参考这句话改口，因为新输入已经变了。但仅凭它改口，不能说这次聊天已经改变了模型参数。大家可以用一句话分辨：它只是带着原来的内部数字处理了新内容，还是程序真的修改并保存了那些数字？

大括号、引号和逗号，是用来划清边界的符号，程序据此读取，不能随手省略。这里的 JSON，英文全称 JavaScript Object Notation，是一种按约定写出结构化数据的文本格式。

⑤ 这批示范怎样用于训练 有监督微调

现在我们手里有了已有基础的模型，也有一批“给出要求和问题，再提供示范回答”的练习。训练时，程序把要求与问题交给模型，检查它对示范回答文字的预测，再依据偏差调整参数。这里的“参照”换成了人工整理好的示范回答，前面训练循环的基本关系仍然成立。

这种用明确示范作为学习参照、在已有模型上继续训练的做法，叫“有监督微调”，英文是 Supervised Fine-Tuning，简称 SFT。“有监督”不是有个人坐在旁边实时盯着显卡，而是这批练习已经提供了要学习的目标，程序可以拿预测与目标比较。

⑨ 回到最开始 模型究竟怎样学东西

现在把两段案例接起来。赛博学姐那边，我们核对通知、建立标准、修改坏回答，准备值得学习的示范；小工具项目这边，我们把需求和参考代码整理成练习，真正运行训练，让程序据此调整参数，再保存成果、加载使用。
